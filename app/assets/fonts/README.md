# Inter

Fuente variable Inter, distribuida con licencia SIL Open Font License 1.1. Licencia completa: `OFL-Inter.txt`.

Descargada el 14 de noviembre de 2026 del [repositorio oficial de Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter), archivo `Inter[opsz,wght].ttf`, conservado aquí como `Inter.ttf`.

Se incluye localmente para que la aplicación no dependa de una descarga de fuentes desde un servicio externo. Inter aproxima la tipografía de las láminas; estas no incluyen una especificación de fuente.
